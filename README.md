# ACS Teaching — 急性冠狀動脈症候群教學投影片

ACLS 講師教學用的 HTML 投影片。以教科書〈第 9 章 急性冠狀動脈症候群〉（陳思州）為架構，逐項對照 **2025 ACC/AHA/ACEP/NAEMSP/SCAI ACS Guideline**，以及 2025 AHA CPR/ECC Part 11（Post-Cardiac Arrest Care）。

**線上播放：** https://hh4832.github.io/ACS-teaching/

## 操作

| 按鍵 | 功能 |
|---|---|
| ← / → 、空白鍵、點擊畫面 | 翻頁（點畫面左側 1/4 回上一頁） |
| F | 全螢幕 |
| N | 講者備註 |
| P | 列印 / 另存 PDF（每頁一張 16:9） |
| 網址加上 `#12` | 直接跳到第 12 頁 |

**手機 / 平板：** 寬度小於 1000 px 或直向螢幕時，自動切換成「閱讀版面」——內容重新排版成單欄、可上下捲動、字體放大到可讀大小；下方工具列可翻頁與開啟講者備註，也可左右滑動翻頁。過寬的表格、流程圖、DAPT 時間軸可在框內左右滑動。桌機與投影維持原本 16:9 版面，列印也一律輸出 16:9。

情境練習頁的題目卡可以點擊顯示答案。

## 內容

- 45 頁，分為辨識、ECG、院前、急診、STEMI 再灌流、NSTE-ACS、藥物、心因性休克 / 心跳停止後照護
- 圖 9-1 至 9-9 以 HTML/SVG 重繪（流程圖、分類表、DAPT 時間軸）
- 每項建議標示 COR（Class 1 / 2a / 2b / 3）
- 「教材 vs 2025 指引」對照頁，列出講課時需更正或補充的地方

## 檔案

單一檔案 `index.html`，不需建置，直接用瀏覽器開啟即可。
